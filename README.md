# Customer--churn
Customer Churn Prediction
This project predicts whether a telecom customer is likely to churn (cancel their subscription) using supervised machine learning techniques.
Highlights:
## 1. Exploratory Data Analysis (EDA) to uncover patterns in customer behavior
## 2. Feature engineering and data preprocessing (handling missing values, encoding, scaling)
## 3. Trained and compared multiple classifiers: Logistic Regression, Decision Tree, Random Forest, and more
## 4. Evaluated models using accuracy, precision, recall, and F1-score

## Tech Stack: Python · Pandas · Scikit-learn · Matplotlib · Seaborn
